# Ajustes para curvas técnicas

Esta versão melhora o treino em pistas sinuosas:

- Velocidade máxima reduzida para 2.7.
- Sensores reduzidos para 110 graus, focando mais na frente do carro.
- Quantidade de checkpoints aumentada para 120.
- Fitness agora recompensa mais:
  - alinhamento com a direção da pista;
  - avanço por checkpoints;
  - velocidade controlada;
  - suavidade.
- Fitness agora pune mais:
  - zig-zag;
  - andar colado na borda;
  - ficar parado;
  - dirigir desalinhado.
- Mutação ajustada para 3.5%.
