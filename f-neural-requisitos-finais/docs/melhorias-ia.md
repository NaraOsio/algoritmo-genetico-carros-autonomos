# Melhorias na IA

Ajustes aplicados:

- Velocidade máxima reduzida para 3.2.
- Rede neural aumentada para 21 → 24 → 2.
- Sensores reduzidos para 130 graus.
- Checkpoints aumentados para melhorar o progresso em curvas.
- Fitness melhorado com alinhamento, suavidade e penalidade de zig-zag.
- IA agora pode acelerar ou frear usando saída entre -1 e +1.
- Aderência lateral aumentada para reduzir drift excessivo.
